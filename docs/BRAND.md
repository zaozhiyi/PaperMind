# PaperMind identity

Product spelling: **PaperMind**. No Chinese secondary name.

A quiet folded-paper mark, mostly open space, with rounded charcoal strokes and a simple wordmark. The interface keeps the document as the main surface. No decorative AI badge or persistent extra controls.

Assets: `public/brand/mark.svg`, `app-icon.svg`, `wordmark.svg`, and `identity.png`. SVG assets are the editable UI source; the PNG is the visual concept. The favicon has slightly stronger strokes to remain legible at small sizes. Dark mode reverses the monochrome mark.

Visual references: [Manus brand](https://manus.im/brand) for restraint, and [Apple design foundations](https://developer.apple.com/design/human-interface-guidelines/foundations) for clarity. The PaperMind mark was created for this project.

The concept was generated with the built-in imagegen tool and then implemented as native SVG. Final prompt direction: “PaperMind, folded-paper outline monogram, continuous fine charcoal strokes, open interiors, medium-light sans-serif wordmark, warm off-white background, no solid black panels, no gradients, shadows, robot, brain or sparkles; clear at 24px.”
