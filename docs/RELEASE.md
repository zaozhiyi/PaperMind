# PaperMind 0.5.0

学习笔记的关系图现在直接出现在正文阅读页。支持 Mermaid flowchart / graph；图稿仍是文档的一部分，默认折叠，可修改和撤销。无需上传到公网图床。此前 0.4.0 的说明保留在下方。

## 图的交付与保存

- Markdown 导入、HTML 中的 language-mermaid 代码块沿用现有文档结构，阅读页按语言识别并绘制。无需迁移旧数据库。
- 导入前检查类型、资源限制与 Mermaid 语法，错误拒绝保存；返回图数量与语法状态，明确显示仍待浏览器核验。普通代码块保持代码。
- 页面默认适应宽度，可切回原始大小；图旁正文保留编辑、批注和讨论。讨论消息中的同类图也使用同一渲染器。
- 图稿随数据库、document.json 和 README.md 保存；同步拉取也校验图稿，README 外部修改仍走原有冲突与锚点保护。
- 仅支持受控的流程/关系图。配置指令、HTML、点击操作和外部资源被拒绝，渲染保持 strict 并清理生成的 SVG；服务器解析在隔离 worker 中执行并有超时。

## 本次验证

- 49 项自动测试通过，TypeScript 与生产构建通过。新增覆盖真实解析器校验、拒绝错误图且原文不变、普通代码区分、导出再导入、数据库重启、同步往返、README 外部编辑和图旁讨论恢复。
- 使用用户已提供的同主题笔记副本作本地回归：CLI 导入两张关系图，真实浏览器显示；刷新与服务重启后仍可见。图旁选区实际打开原文讨论，图稿编辑产生错误时页面明确提示，撤销后恢复绘制。
- 同一笔记通过实际同步实现与本地 FakeGithub 传输适配器，拉入独立 SQLite 数据目录，再启动服务并用浏览器确认两图与原文批注仍在。未把私人笔记上传到 GitHub；此项不冒充真实远端同步验收。
- 用户材料、截图、测试数据库与真实笔记内容均不进入本公开代码仓库。没有重新调用 PaperMind 的生产模型生成或问答。

## 升级

更新代码，运行 npm ci 与 npm run build，然后沿用原数据目录和端口停止、重启 PaperMind。运行版本在 /api/health 查看。旧的纯表格笔记须重新生成图稿并带最新 revision 导入；升级本身不会自动改写笔记。

# PaperMind 0.4.0

本机优先的学习文档工作台。生产构建在 localhost 运行，不是公网托管服务，也尚未发布到 npm。安装与完整流程见 [WORKFLOW.md](WORKFLOW.md)。

## 本次变化

- 独享私有知识库自动双向同步，每两分钟检查远端与本机改动，支持暂停、手动同步和状态查看。
- 配置、每轮同步与推送前校验仓库私有性、所有者、协作者和待接受邀请；绑定后禁止手动上传到其他仓库。
- 整篇文章 AI 对话随文档同步；恢复和冲突副本保留消息。
- 两台电脑按内容指纹判断改动，避免本地版本号和时间戳导致重复提交。
- 跨文章粘贴时去除不属于当前文章的批注引用，保留文本和格式。

## 验证

- 46 项自动测试通过，TypeScript 检查及生产构建通过。包含隐私检查、推送前权限变化、同步冲突、无改动不写入、整篇对话往返与跨文档批注防护。
- 在授权的真实私有仓库完成上传，再向一个全新 SQLite 数据目录拉取。22 篇文档、5 条选段讨论恢复后，正文与讨论内容指纹全部一致。正式笔记中没有整篇文章对话，因此整篇对话恢复由隔离测试验证，未混称为实仓样本验证。
- 本机原始材料 230 个文件已按 SHA-256 核对完整性；私人资料、标题、仓库地址和验收快照不包含在本公开源码仓库中。
- Chrome 实际打开导入笔记，显示自动同步状态和绑定的私有仓库。另验证匿名访问知识库返回 404，GitHub Pages 未启用。
- 此次没有重新执行模型生成验收。此前版本已验证真实模型问答、写回和撤销；记录的网络中断仍可能发生。

## 当前边界

自动同步需要本机 PaperMind 服务运行；关机、休眠或服务停止时不执行，重启电脑后需重新启动。冲突停止本轮写入，须通过拉取预览处理。单次目录最多 100 篇、同步内容累计 8 MB。归档材料是历史快照；外部 Agent 的新 Markdown 必须先交付给 PaperMind。

旧版本通用聊天、机器设置、模型凭据和本地撤销栈不属于文档同步。GitBook 原生评论不互通；旧页面评论按原始文件保留，不假装自动恢复准确锚点。Markdown 无法完整表达的页面组件和交互图可能以文本或代码块呈现，原始页面快照另行保留。多人实时协作未提供。生产构建仍有 bundle 大小提示。

## 兼容性

主命令 `papermind`；旧 `yejian` 入口兼容。数据目录、浏览器偏好和已有交换格式保留。更名与升级不搬动笔记或更换模型授权。
