# PaperMind 0.3.0

本机优先的学习文档工作台。生产构建在 localhost 运行，不是公网托管服务，也尚未发布到 npm。

## 已验证

- 41 项自动测试通过，生产构建通过；自动测试覆盖同源会话保护、选区与格式保留、版本冲突、讨论写回、撤销、事务回滚和数据库重启。
- 外部 CLI 的创建、读取、幂等重试和带版本更新经过真实 HTTP 验证。
- 本机浏览器验收了目录、批注、固定文档顺序、高亮和自动保存、浮层关闭与恢复。
- 配置的真实模型完成文章问答、段落问答、一次写回和撤销，未选中正文保留。发生过一次网络中断，重试后成功。
- GitHub 上传、拉取与冲突副本通过隔离模拟测试；尚未使用用户指定的笔记仓库完成真实往返。

## 当前边界

整篇文章问答仅保存在本机，GitHub 包含正文和段落批注。多人实时协作、GitBook 原生评论互通、后台自动同步尚未提供。模型权限由所连接账号决定，网络中断可能需要重试。生产构建有 bundle 大小提示。

## 品牌兼容

新主命令是 `papermind`，旧 `yejian` 入口兼容；数据位置、浏览器偏好和已有导出格式保留。更名不会移动笔记或更换模型授权。
