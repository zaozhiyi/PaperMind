# 交付验收 · 检索学习笔记

这是一篇由外部 Agent 通过命令行交付的验收笔记，用来检查阅读目录、后续更新和讨论定位。外部更新已送达，阅读页面会自动刷新正文。

## 第一部分 为什么需要检索

### 第 1 章 模型不知道你的资料

模型能够回答一般性问题，但不会自动知道你刚刚保存的学习笔记。检索的作用，是先从资料中找到与问题有关的内容，再把这些内容交给模型。

例如，你问“上周学过的缓存命中是什么意思”，系统应该先找到自己的缓存笔记，而不是假定模型已经读过那篇文档。

## 第二部分 从零搭一个检索系统

### 第 2 章 按字找：倒排索引

倒排索引记录“哪些文档出现过这个词”。搜索一个明确的名称、编号或原句时，这种方式通常很直接。它像一本书后面的索引：先找到词，再按页码找到原文。

### 第 3 章 按意思找：向量

同一件事可以有不同说法。向量检索尝试把文本表示成一组数字，通过比较这些数字找到含义接近的内容。含义接近只是一条线索，仍然需要检查原文是否真的回答了问题。

### 第 4 章 从候选资料中继续筛选

找到几篇相关资料之后，还需要比较哪段内容最能回答当前问题。资料可能提到了同一个词，却讨论的是另一件事，因此不能把“搜索到了”直接当成“已经找到答案”。

## 第三部分 把资料交给模型

### 第 5 章 解释答案从哪里来

模型回答时应说明使用了哪段材料。引用让读者能回到原文检查：这句话是资料明确写出的，还是模型根据资料作出的推断。

| 环节 | 要解决的问题 |
| --- | --- |
| 检索 | 相关资料在哪里 |
| 阅读 | 资料究竟说了什么 |
| 回答 | 如何根据资料解释当前问题 |

### 第 6 章 用自己的例子验证

学习时，可以选中一段没看懂的文字，让 AI 换一个例子解释。讨论清楚后，再把有帮助的解释融入正文。这样留下的是持续完善的笔记，而不是散落在多个聊天里的答案。

## 第四部分 保存与继续学习

### 第 7 章 在不同电脑之间继续

把正文与讨论一起保存到自己的仓库，在另一台电脑恢复后继续阅读。如果两边都修改过同一篇笔记，应先看清差异并保留副本，再决定如何整理。
